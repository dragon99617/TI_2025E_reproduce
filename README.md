# TI 2025E Reproduce

本项目用于复刻 2025 年全国大学生电子设计竞赛 E 题“简易自行瞄准装置”相关方案


## 项目目标

- 完成小车沿黑色方形轨迹自动循迹
- 支持设置行驶圈数 N
- 实现静态自动瞄准靶心
- 实现行驶中连续瞄准
- 支持后续扩展行驶中画圆等发挥功能
- 保持底盘控制链路由 TI MSPM0 系列 MCU 完成，便于满足题目约束

## 系统架构

```text
灰度传感器 / 编码器
        |
        v
LP-MSPM0G3507  --->  H 桥驱动  --->  底盘电机 x2
        |
      UART
        |
        v
达妙 H427  <---  maxicam 视觉模块
        |
       CAN
        |
        v
DM4310-2EC x2  --->  二维云台  --->  激光模块
```

## 硬件组成

| 模块 | 推荐器件 | 作用 |
| --- | --- | --- |
| 底盘主控 | LP-MSPM0G3507 | 循迹、编码器、底盘电机闭环 |
| 瞄准主控 | 达妙 H427 | 云台控制、视觉解析、激光控制 |
| 视觉模块 | maxicam | 靶面和激光点识别 |
| 云台电机 | 达妙 DM4310-2EC x2 | yaw/pitch 二自由度云台 |
| 底盘电机 | MG513X 或同类编码电机 x2 | 差速运动 |
| 电机驱动 | 双路 H 桥驱动 | 接收 MSPM0 的 PWM/DIR 控制 |
| 循迹传感器 | 7/8 路灰度传感器 | 黑线检测 |
| 电源 | 6S 锂电 + BEC/降压模块 | 分路供电 |
